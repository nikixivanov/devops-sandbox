## 🚀 Projects & Labs

### 1. Automated CentOS Stream 9 Environment
A clean, automated local development environment utilizing EuroLinux Vagrant boxes.

* **Directory:** `/vagrant/centos-stream-9`
* **Key Features:** Static IP provisioning, resource optimization (2 vCPUs, 2GB RAM), x86-64 microarchitecture compatibility.

#### How to run it:
```bash
cd vagrant/centos-stream-9
vagrant up
vagrant ssh
```
